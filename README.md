# Surplux

Surplux is a Django-based food surplus management platform that connects:

- Donors (restaurants, households)
- Buyers
- NGOs

## Features

- ML-based shelf life prediction
- Grocery expiry detection
- Food marketplace
- NGO donation requests
- Donor approval system
- Purchase request system

## Tech Stack

- Django
- Python
- SQLite
- HTML/CSS
- Machine Learning (scikit-learn)

## Setup

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
